# 研发投入与企业绩效回归分析

## 项目概述

基于A股新能源行业上市公司财务数据，使用OLS回归分析研发投入对企业绩效（ROA/ROE）的影响，并通过更换变量、更换样本、稳健标准误三种方式进行稳健性检验。

## 技术栈

- Stata 19 MP
- estout（回归结果输出）
- winsor2（缩尾处理）

## 模型设计

### 基础回归

| 模型 | 自变量 | 因变量 | 控制变量 |
|------|--------|--------|----------|
| 模型1 | 研发投入强度 | ROA | 资产负债率、公司规模 |
| 模型2 | 研发投入强度 | ROE | 资产负债率、公司规模 |

### 稳健性检验

| 检验 | 方法 | 目的 |
|------|------|------|
| 检验1 | 更换自变量为研发投入绝对值 | 验证自变量定义不影响结论 |
| 检验2 | 更换因变量为ROE | 验证因变量选择不影响结论 |
| 检验3 | 使用稳健标准误（robust） | 处理异方差问题 |

## 数据预处理

- 缺失值检查与删除（misstable + drop if missing）
- 生成研发投入强度 = 研发投入 / 营业收入 × 100
- Winsorize缩尾处理（1%和99%分位数）

## 输出文件

| 文件 | 说明 |
|------|------|
| `rd_performance_regression.do` | Stata源代码 |
| `sample_data.csv` | 样本数据 |
| `regression_results.rtf` | 回归结果对比表 |
| `regression_log.txt` | 操作日志 |

## 运行方式

在Stata中打开 `rd_performance_regression.do`，修改工作路径后执行全部代码。

## 应用场景

- **盈利能力评估**：高研发投入企业的盈利能力需考虑长期效应
- **估值辅助验证**：回归模型可作为可比公司估值法的辅助工具
